## 当前项目主目录说明

- `app/`：FastAPI 后端代码。
- `bsapp/`：当前主要 UniApp/H5 前端代码。
- `tests/`：后端自动化测试。
- `docs/`：正式技术文档、迭代记录、答辩文档。
- `demo_tests/`：按角色和场景整理的手动测试材料。
- `期末展演/`：答辩 PPT、演讲稿、QA 和展演要求。
- `frontend/`：历史前端镜像/备份，当前开发以 `bsapp/` 为准。

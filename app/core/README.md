# core - 基础设施

这个目录放的是系统底层的东西，其他模块都依赖它们。

| 文件 | 干什么的 |
|------|---------|
| config.py | 读 `.env` 配置文件，统一管理数据库地址、JWT密钥、模型API地址等 |
| database.py | MySQL 异步连接池，`get_db()` 函数给上层拿数据库会话 |
| redis.py | Redis 连接池（缓存用的，目前连接配好了但还没有实际使用） |
| security.py | JWT token 生成/验证 + 密码哈希 |

换环境（比如换数据库地址）只需要改 `.env`，不用动这些文件。

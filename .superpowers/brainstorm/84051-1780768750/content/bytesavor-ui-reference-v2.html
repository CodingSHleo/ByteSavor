ByteSavor UI 方案 v2 · 参考 ui.png

设计基准已切换为：清新、友好、轻量、专注、习惯养成感。下面是把参考图转译到 ByteSavor 的具体方式。

从参考图提取的设计 DNA

颜色

浅雾绿背景 + 白色卡片 + 薄荷绿主色。橙、黄、蓝、紫只做局部状态，不做大面积渐变。

布局

顶部问候/标题，主体卡片纵向组织，底部 tab 固定。信息块之间用留白和轻阴影分层。

组件

目标列表、习惯列表、统计环图、趋势图、状态标签、圆角图标块、轻量提示卡。

气质

不压迫、不炫技，像一个每天打开都舒服的小工具。ByteSavor 要在这个基础上加入 AI 饮食决策感。

页面映射

首页 home

套模板 A：今日状态、今日目标、BYTE 进度、推荐菜谱。主按钮是拍照识别。

识别页 ingredient

套模板 B：扫描画布、阶段进度、食材列表、确认按钮。

健康看板 dashboard

套模板 C：统计总览、营养环、缺口列表、推荐下一步。

探索/知识

套参考图中“习惯库”页：顶部标签、轻卡片列表、图标色块。

购物清单

套任务列表：统计头、可编辑清单、底部操作栏。

我的/历史

套个人中心/成就系统：头像、健康摘要、记录时间线。

执行原则

保留

  • 现有 API 和数据字段
  • 现有页面路由含义
  • 现有本地缓存、历史记录、设置逻辑
  • 现有识别/推荐/清单/反馈闭环

重构

  • 统一颜色、圆角、阴影、间距
  • 补齐并统一图标系统
  • 减少 emoji 和蓝紫渐变
  • 把页面重排成状态、任务、统计三类模板

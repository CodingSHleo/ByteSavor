## 修复详情

### 1. 推荐食材硬约束（decision.py）

**根因**：`_rank()` 中 `s = s_ing * 0.5 + s_tag * 0.3 + s_pref * 0.2`，食材权重只有 50%。"芹菜炒牛肉"命中牛肉（50%覆盖），加标签分就能超过阈值。

**修复**：
- 新增 `_get_user_ingredient_coverage()`：不匹配任何用户食材的菜谱直接排除
- 完全命中加额外分（+0.1）
- 食材权重从 0.5 → 0.55，用户覆盖率从 0.65 → 0.8
- 新增 `ING_MISSING` 理由码，显示"缺少: 韭黄"
- 推荐结果第一项增加 `_meta`：matched_ingredients / missing_ingredients

### 2. 菜谱搜索增强（explore.vue）

**根因**：`r.title.toLowerCase().includes(kw)` 只做连续子串匹配。"韭黄炒蛋"不能匹配"韭黄炒鸡蛋"。

**修复**：
- `_searchRecipes()`：搜索标题 + 食材名 + 标签
- `_tokenizeQuery()`：中文 token 化，支持同义词扩展
- 每个 token 必须全部命中（AND 逻辑）

### 3. 推荐刷新（decision.py + schemas.py）

**根因**：相同 ingredients + constraints → 相同缓存 key → 返回缓存。

**修复**：
- `DecisionRequest` 新增 `refresh: bool = False`
- `refresh=true` 跳过缓存

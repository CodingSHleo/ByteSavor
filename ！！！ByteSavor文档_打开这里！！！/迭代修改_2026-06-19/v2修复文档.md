## P1-1：MemoryContext previous_state

**问题**：`app/routers/agent.py` 的 `build_memory_context()` 调用始终传 `previous_state=None`。同一 conversation 的第二轮无法看到上一轮识别的食材/推荐。

**修改文件**：
- `app/agent/langgraph_runtime.py`
- `app/routers/agent.py`

**修改前（agent.py）**：
```python
# 组装 MemoryContext
memory_context = await build_memory_context(
    db, user_id or None,
    previous_state=None,  # 永远是 None
    goal=goal,
)

tools = ToolRegistry()
...
runtime = ...
result = await runtime.run(...)
```

**修改后**：
```python
tools = ToolRegistry()
...
runtime = ...  # 先创建 runtime

# 前置读取上一轮会话状态
previous_state = await runtime.get_previous_state(req.conversation_id)
memory_context = await build_memory_context(
    db, user_id or None,
    previous_state=previous_state,  # 真实上一轮状态
    goal=goal,
)
result = await runtime.run(...)
```

**新增代码（langgraph_runtime.py）**：
```python
async def get_previous_state(self, conversation_id: str) -> dict | None:
    """公开方法，供路由层读取上一轮会话状态用于 MemoryContext。"""
    return await self._load_previous_state(conversation_id)
```

## P1-2：_result() 返回 memory 字段

**问题**：`AgentRuntime._result()` 不返回 `memory_context` 和 `memory_used`，路由层用静态构建值覆盖，runtime 内 state 的 memory 丢失。

**修改文件**：
- `app/agent/runtime.py`
- `app/routers/agent.py`

**修改前（runtime.py _result）**：
```python
return {
    ...
    "events": state["events"],
    "errors": state["errors"],
    "degraded": bool(state["errors"]),
}
```

**修改后**：
```python
return {
    ...
    "events": state["events"],
    "errors": state["errors"],
    "degraded": bool(state["errors"]),
    "memory_context": state.get("memory_context", {}),
    "memory_used": state.get("memory_used", []),
}
```

**修改前（agent.py 后处理）**：
```python
result["memory_context"] = memory_context
result["memory_used"] = build_memory_used(memory_context)
```

**修改后**：
```python
result["memory_context"] = result.get("memory_context") or memory_context
result["memory_used"] = result.get("memory_used") or build_memory_used(result["memory_context"])
```

## P1-3：统一事件顺序

**问题**：AgentRuntime 的事件顺序是 `final → evaluation`，LangGraph 的顺序是 `evaluation → final`，两个 runtime 不一致。

**修改文件**：`app/agent/runtime.py`

**修改前（_finish_run）**：
```python
# 先 append final event
state["events"].append({"type": "final", ...})
# 再 evaluate
eval_result = evaluate_hard(state)
state["events"].append({"type": "evaluation", ...})
```

**修改后**：
```python
# 先 evaluate（在 final 之前）
eval_result = evaluate_hard(state)
state["events"].append({"type": "evaluation", ...})
# 再 append final event
state["events"].append({"type": "final", ...})
```

**统一后顺序**：`ROUTING → EXECUTING → EVALUATING → FINISHED`

## P1-4：reply 提取逻辑

**问题**：`_result()` 用 `reversed(events)` 取第一个有 `message` 的 event，如果 evaluation event 有 message 字段就会取错。

**修改文件**：`app/agent/runtime.py`

**修改前**：
```python
final_message = next(
    (event["message"] for event in reversed(state["events"]) if "message" in event),
    "",
)
```

**修改后**：
```python
# 只从 type=="final" 的 event 取 reply
final_message = next(
    (event.get("message", "") for event in reversed(state["events"]) if event.get("type") == "final"),
    "",
)
if not final_message:
    final_message = AgentRuntime._build_reply(state)
```

```python
codes = set()

if "LOW_CONFIDENCE_INGREDIENT" in codes:
    prompts.append({...})  # INGREDIENT_CONFIRM
```

## P1-12：handleConfirmation retry 用错输入

**问题**：用户点击"换一批推荐"时，`agentMessage.value` 被设为助手回复文本（如"已找到 3 个菜谱..."），导致第二轮 Agent 意图漂移。

**修改文件**：`bsapp/src/pages/home/home.vue`

**修改前**：
```javascript
if (option.action === 'retry') {
  agentMessage.value = msg.text || ''  // msg.text 是助手回复
  sendAgentMessage()
}
```

**修改后**：
```javascript
// assistant 消息存储原始用户输入
agentMessages.value.push({
  ...
  sourceText: m,  // ← 保存原始输入
})

function handleConfirmation(promptIndex, option, msg) {
  if (option.action === 'retry') {
    const lastUser = [...agentMessages.value].reverse().find(x => x.role === 'user')
    agentMessage.value = msg.sourceText || (lastUser ? lastUser.text : '')
    if (agentMessage.value.trim()) sendAgentMessage()
  }
}
```

```python
class CorrectionLogRequest(BaseModel):
    action: str = Field(..., pattern="^(rename|delete|merge|weight_adjust|add)$")
    source: str = Field(default="sense", pattern="^(sense|inventory)$")
    original_name: str = ""
    corrected_name: str = ""
    confidence: float = Field(default=0, ge=0, le=1)
    meta: dict = Field(default_factory=dict)
```

**correction_logs.py 修改前**：
```python

        ..., action=body.get("action", "rename"), ...
```

**correction_logs.py 修改后**：
```python
async def record_correction(body: CorrectionLogRequest, ...):
    record = await correction_svc.log_correction(
        ..., action=body.action, ...
```

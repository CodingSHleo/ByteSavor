## 后端错误语义变化

| 场景 | 修改前 | 修改后 |
|------|--------|--------|
| 删除不存在帖子 | success + deleted=false | error: POST_NOT_FOUND |
| 点赞不存在帖子 | success + error dict | error: POST_NOT_FOUND |
| 非法 category | 空列表 | error: INVALID_CATEGORY |
| 非作者删除 | error: FORBIDDEN | error: FORBIDDEN（保持不变） |
| 空评论 | error: INVALID_COMMENT | error: INVALID_COMMENT（保持不变） |

## 分页支持

```
GET /v1/community/posts?category=all&limit=20&offset=0
```

返回新增字段：`total`, `limit`, `offset`, `has_more`

## liked_by_me

- 列表和详情对登录用户返回 `liked_by_me: true/false`
- 未登录始终 false
- 使用 `get_optional_user` 不强制登录

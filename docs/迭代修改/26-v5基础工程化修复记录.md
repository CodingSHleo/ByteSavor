## Task 1 详情

**pytest.ini** 新增 markers：
```ini
markers =
    db: tests that require MySQL/Redis or persistent database access
    eval: offline evaluation runner tests or eval-related checks
    frontend: frontend smoke/build checks
```

**10 个 DB 测试文件** 的 `pytestmark` 从单一 mark 改为 list：
```python
# 修改前
pytestmark = pytest.mark.asyncio(loop_scope="session")

# 修改后
pytestmark = [pytest.mark.asyncio(loop_scope="session"), pytest.mark.db]
```

文件列表：test_auth.py, test_decision.py, test_meals_inventory.py, test_feedback_memory.py, test_inventory_stats.py, test_recipe_checker.py, test_favorites.py, test_community.py, test_community_recipe_flow.py, test_agent_tools_inventory_favorites.py

**验证**：`pytest --collect-only -q` 无 unknown marker warning；`pytest -m db --collect-only -q` 收集到 24 个 DB 测试。

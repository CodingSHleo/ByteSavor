# ByteSavor V3.0 答辩演示测试报告

## 测试环境

- 后端：FastAPI + MySQL + Redis，macOS，端口 8000
- 前端：uni-app (Vue3+Vite5)，H5 模式，端口 5173
- AI 模型：Qwen-VL-Max (视觉) + DeepSeek-Chat (推理) + Ollama qwen2.5:1.5b (本地备份)
- 数据：2573 道菜谱（Ta-da 数据集 + 手写 60 道）
- 测试时间：2026-06-08

---

## 场景一：拍照识别 → 个性化推荐 → 反馈学习（BYTE 全闭环）

### 测试流程
1. 用户注册/登录，设置饮食偏好（减脂 + 辣味 + 高蛋白）
2. 拍一张食材照片（冰箱/菜板/厨房台面）
3. 后端调用 Qwen-VL-Max 识别食材，返回名称、新鲜度、置信度、外观特征、估算分量
4. 根据识别的食材 + 用户偏好，推荐引擎从 2573 道菜谱中匹配，按个性化打分排序
5. 点击菜谱查看详细做法、营养成分、文化背景
6. 品尝后评分，系统自动更新用户偏好

### 涉及接口
| 步骤 | 接口 | 说明 |
|------|------|------|
| 注册 | `POST /v1/auth/register` | 微信 OpenID 登录 |
| 设偏好 | `PUT /v1/user/profile` | 目标+口味 |
| 拍照 | `POST /v1/sense/analyze` | VLM 食材识别 |
| 推荐 | `POST /v1/decision/meal-plan` | 个性化推荐引擎 |
| 详情 | `GET /v1/recipes/{id}` | 菜谱步骤+营养+文化 |
| 反馈 | `POST /v1/feedback/meal` | 评分→偏好学习 |

## 场景二：多菜谱合并 → 购物清单 + 选菜建议

### 测试流程
1. 选择多道菜谱（如香辣牛肉西兰花 + 南瓜炖牛肉 + 清蒸鲈鱼）
2. 系统自动合并同名食材数量（牛肉 300g + 400g = 700g）
3. 每项食材附带挑选建议（如"牛肉：挑选纹理清晰、呈樱桃红色、大理石花纹均匀的"）
4. Agent 一句话"牛肉南瓜鲈鱼做三道菜"自动走全流程生成清单

### 涉及接口
| 步骤 | 接口 | 说明 |
|------|------|------|
| 合并 | `POST /v1/task/merge-list` | 同名累加+挑选建议 |
| Agent | `POST /v1/agent/execute` | 自然语言全流程 |

### 挑选建议示例
- 牛肉：挑选纹理清晰、呈樱桃红色、大理石花纹均匀的，按压有弹性
- 西兰花：选深绿色、花球紧实饱满、无黄斑的，茎秆脆嫩可掐断
- 鲈鱼：选体表银亮、眼睛饱满凸出、鳃丝鲜红的活鱼

`场景二_清单导出/` 文件夹

## 场景三：水果品质鉴定

### 测试流程
1. 拍西红柿/西瓜/榴莲照片
2. VLM 识别品种 + 外观特征 + 新鲜度
3. 系统匹配品质标准（优/中/差），给出挑选依据
4. 综合输出：品质等级 + 外观描述 + 挑选标准 + 购买建议

### 涉及接口
| 步骤 | 接口 | 说明 |
|------|------|------|
| 鉴定 | `POST /v1/quality/assess` | VLM+知识库综合评估 |

### 品质标准示例
| 水果 | 优等标准 |
|------|---------|
| 西红柿 | 色泽鲜红均匀、果形圆润饱满、果蒂翠绿、触感微软有弹性、无裂痕虫眼 |
| 西瓜 | 拍打听声清脆、瓜脐小而凹、瓜藤翠绿卷曲、纹路清晰、同等大小较重 |
| 榴莲 | 浓郁香味、果刺大而疏、底部有裂缝、摇晃有果肉晃动感、果壳金黄 |

## 场景四：热量识别与营养分析

### 测试流程
1. 拍一顿饭的照片（如米饭 + 鸡胸肉 + 西兰花）
2. VLM 识别食物 + 估算分量（克数）
3. 系统计算热量、蛋白质、碳水、脂肪
4. 用份量参照物说明（一拳米饭 = 150g = 175kcal）
5. 对比用户每日目标，给出"还需补充"或"已超标"建议
6. 记录到营养仪表盘

### 份量参照体系
| 参照物 | 对应食物 | 重量 | 热量 |
|--------|---------|------|------|
| 一拳头 | 米饭/主食 | 150g | ~175kcal |
| 一掌心 | 肉/鱼/蛋白质 | 100g | ~150kcal |
| 双手捧 | 蔬菜 | 200g | ~60kcal |
| 大拇指 | 油/酱料/脂肪 | 15g | ~135kcal |

### 涉及接口
| 步骤 | 接口 | 说明 |
|------|------|------|
| 分析 | `POST /v1/nutrition/analyze-meal` | VLM+营养计算+日标对比 |
